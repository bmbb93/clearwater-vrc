# 焼き込みデータとマテリアルはシーンごとのフォルダーに置き、持ち主はフォルダー名のシーン GUID で決める

これまで、Bake の結果と水・水底・水中・空のマテリアルは `Assets/Clearwater/Generated` に 1 組しかなく、どのシーンも同じファイルを参照していた。別のシーンを Bake すると上書きされるので、デモを開くたびに焼き直し、自分のシーンに戻ったらまた焼き直す必要があった。

シーンによって変わるものは、シーンごとのフォルダー `Generated/(シーン名)_(シーンの GUID の先頭 8 桁)/` に置くことにした。対象は、海岸・スタンプ・自分の地形・プールの焼き込み、歩ける地面、海の広さで決まるメッシュ、それらを読むマテリアル（Water・Seabed・Underwater・AvatarCaustics・Sky・UserBeach）。シーンによらないもの（波のスペクトルと FFT の CRT、光の模様の格子とカメラの出力、Swash の表、空の LUT、トーンマッピング、小石）は `Generated/` 直下で共有したままにする。

フォルダーがどのシーンのものかは、名前の末尾の GUID で決める。別の印は置かない。シーンの名前を変えても GUID は変わらないので、フォルダーは同じシーンのものとして見つかる。Bake のとき、シーンが参照しているマテリアルが自分のフォルダーになければ、次のようにしてから焼く。

- `Generated/` 直下にある（前の版で作った）なら、自分のフォルダーへ移す。移動では GUID が変わらないので、シーンの参照は切れない
- 別のシーンのフォルダーにある（シーンを複製した、同じデータを共有していた）なら、自分のフォルダーへ複製し、シーンの参照を付け替える。調整した値は複製に引き継がれる

焼き込みの結果（テクスチャやメッシュ）は複製しない。Bake が自分のフォルダーに作り直し、マテリアルと物に付け直す。

データを共有したいシーンのための設定は作らなかった。規則を「シーン 1 つにデータ 1 組」だけにしておく方が分かりやすく、共有していると片方の Bake がもう片方を黙って変えてしまう。

## Consequences

- シーンを増やすと、そのシーンの分だけ容量が増える（既定の海岸で約 40 MB、自分の地形を使うとさらに約 32 MB）。ワールドには開いたシーンの分しか入らないので、アップロードの大きさは変わらない。
- マテリアルで調整した値（波・明るさ・雲など）はシーンごとに別になる。
- 同じ海岸を使う 2 つのシーンでも、海岸を変えたらそれぞれで Bake する。
- シーンを消しても、そのフォルダーは残る。要らなければ手で消す。
- 前の版の `Generated/` 直下の焼き込みは、最初に Bake したシーンに移る。そのシーンが参照していないもの（別のシーンが使っていた自分の地形やプールの焼き込み）は直下に残るので、要らなければ手で消す。
