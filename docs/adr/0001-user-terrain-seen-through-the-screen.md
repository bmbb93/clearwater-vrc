# User terrain は自分のマテリアルのまま画面から見せ、光の模様などは投影で重ねる

水面はもともと Generated terrain を計算で辿って水底を描いており、画面上のメッシュは見ていない。User terrain では、メッシュから形だけをベイクして Bed look で塗る（Clearwater Stamp と同じ方式、見た目の一貫性は保証できる）のではなく、メッシュ自身のマテリアルを水越しに画面（grab と深度）から取って見せることにした。自分のアセットの見た目を使いたいことが User terrain を使う理由そのものだからで、画面の外や反射の中で取れない所はベイクした形から計算した色で補い、Caustics と浜の濡れ・泡・打ち上げの水膜は User terrain のレイヤーへ上からの投影で重ねる。

## Consequences

- 画面の端・Snell の窓・全反射の鏡像では、見えている物しか取れないため、形から計算した色との切り替えが生じる。
- Caustics と浜の表現の投影のため、User terrain のメッシュをもう一度描く分の負荷がかかる。
- Walkable area の内側の当たり判定はユーザーのメッシュに任せ、パッケージは作らない。
