# Clearwater Coast

VRChat ワールドに、歩いて入れる透明な浅瀬と海岸を作るパッケージです。水面の反射・水底の光の網（コースティクス）・波音に合わせて寄せては返す波打ち際・潜ったときの水中表現を含みます。元になった WebGL デモは [clearwater by Aureliengmz](https://github.com/Aureliengmz/clearwater)（MIT、`LICENSE-clearwater.txt`）です。

PC 向けです（GPU 計算を多用するため Quest では動きません）。VRChat Worlds SDK 3.10 以降が必要です。

## 入れ方

- ALCOM / VCC の「User Packages」にこのフォルダを追加し、プロジェクトに追加する（プロジェクトにコピーされます）
- またはこのフォルダをワールドのプロジェクトの `Packages/` に置く（埋め込みパッケージ）
- パッケージ自体を編集しながら使うときは、プロジェクトの `Packages/manifest.json` の `dependencies` にこのフォルダへの参照を書きます（コピーせず、このフォルダを直接読みます）。パスは `Packages/` からの相対でも書けます

  ```json
  "com.vbamboo.clearwater": "file:../../../Packages/com.vbamboo.clearwater"
  ```

## 使い方

### 新しいシーンから始める

`Tools > Clearwater > Build Scene` を実行すると、`Assets/Clearwater/Scenes/Clearwater.unity` に水・砂浜・太陽・スポーン地点入りのシーンができます。2 回目以降は素材だけを作り直し、シーンに手で置いた物やワールド ID はそのまま残ります。シーンを初めから作り直すときは `Recreate Scene` を使います。

### 既存のワールドに足す

ワールドのシーンを開いて `Tools > Clearwater > Add to Current Scene` を実行します。水一式と、まっすぐな海岸（編集用）が追加されます。最初に「Clearwater の空と太陽も使うか」を聞かれます。使う場合は Build Scene と同じ空・太陽（Sun (Clearwater)）になり、ワールドの Directional Light はオフになります（削除はしません）。使わない場合はワールドの太陽をそのまま使い、影が無効なら有効にします。あとから切り替えるときは `Tools > Clearwater > Use Clearwater Sky and Sun` を使います。水は奥行き情報を使うため、影は有効のままにしてください。Reference Camera の Far Clip は Sea size の 0.8 倍（初期値なら 4000 m）にしてください。

## 海岸を描く（Coast (editor only)）

シーンの「Coast (editor only)」を選ぶと、Scene ビューに波打ち際の線が出ます。

- 点をドラッグして動かす。線の途中の「+」で点を追加、点を選んで Delete で削除
- 「Line」で線の種類を選びます：Straight（点を直線で結ぶ）/ Smooth（点を通るなめらかな曲線、初期値）/ Handles（イラストレーターのパスのように、各点の 2 本のハンドルで向きと曲がり具合を決める）
- Handles では、選んだ点と両隣の点にハンドル（四角）が出ます。ドラッグで曲率を変え、Alt を押しながらドラッグすると角（コーナー）になります。Inspector の「Smooth point / Corner point / Auto handles」で点ごとに切り替えられます。「+」で点を足しても曲線の形は変わりません
- 矢印が海の側です（線の進む向きの左側）。逆なら「Reverse direction」
- 開いた線は両端の先へまっすぐ続きます。「Closed」にすると輪（島・湖）になります
- 「Shore waves」をオフにすると、波打ち際の波（寄せ波・砕波・駆け上がり・泡・濡れた砂）と波打ち際の波音がなくなり、岸の水は静かになります（湖や池向け）。沖の小さな波と、遠くの海の環境音は残ります
- うねりの向き：波は沖から一方向に寄せ、浜ごとにその向きへ開けている分だけ届きます。湾の奥は湾口から入る分だけ、波が沿って走る壁ぎわはほとんど砕けません（波の高さ・駆け上がり・白波・泡・波音の大きさに反映）。届くタイミングも向きに合わせて変わり、湾の奥には遅れて届き、斜めに寄せる波は浜に沿って順に砕けていきます（浅いほど遅くなる波の速さで計算。波音は聞こえてくる浜の波に合わせます）。`Swell direction auto`（初期値）はこのオブジェクトのまわり（約 200 m）の海岸が平均して向いている正面から。外すと `Swell from`（ワールド +Z から時計回りの角度）で向きを決めます。`Swell spread`（初期値 25°）を広げると、湾の奥や横向きの浜にも波が回り込みます。Scene ビューの「swell」の矢印が向きです
- 断面：`Gentle Beach`（遠浅の浜、数値で調整）か `Curve`（波打ち際からの距離に対する地面の高さを曲線で描く）
- 断面のプリセット：「Preset」で選んで Apply。遠浅の浜（数値）/ 急な浜 / 砂州のある浜 / 礁湖（広い浅瀬）/ 湖岸（Shore waves オフ向け）/ 磯の急斜面 / 丘の下の遠浅の浜（遠くからも陸が見える）。遠浅の浜以外は `Curve` として入るので、そのまま曲線を手直しできます
- 「Reset line」で線を初期のまっすぐな線（3 点、200 m）に戻します（断面などの設定はそのまま）。すべての設定を初期値に戻すときは、コンポーネントの ⋮ メニューの Reset を使います
- 変更したら **Bake**。水・海底・波・歩ける地面・波音の位置が形に合わせて更新されます

海の広さは「Sea size」（初期値 5000 m 四方、水のオブジェクトが中心）で変えられます。Bake で水面・遠くまで描く地面・水中の表現が合わせて変わり、水面の端は遠くのもやに溶け込みます。カメラの Far Clip は Sea size の 0.8 倍ほど必要です。足りないと Inspector に警告と「Set ○○ m」ボタンが出ます（ワールドの Reference Camera に設定されます）。

黄色の四角が細かく焼き込む範囲、緑の四角が歩ける地面の範囲（端に見えない壁）、水色の四角が海の範囲（Sea size）です。

### 歩ける範囲の外側の海岸線

線は歩ける範囲の外まで描けます。遠くに点を置けば、岬・湾・対岸などの形になり、水面・遠景の地面・沖の波がその形に沿います。黄色の四角の外は、海全体（水色の四角）を粗く焼き込んだデータ（初期値 5000 m / 1024 = 約 5 m 間隔、`Outer resolution`）で描きます。海の外では、線はそのまま同じ向きに続きます。

- 遠くの陸は低いと水平線に埋もれて見えません。見せたいときは断面を `Curve` にし、陸側（マイナス側）を高くします
- 線が長くても、歩ける範囲の近くは約 1 m 間隔で細かく焼き込みます。遠くの区間ほど粗くなります（線全体で最大 512 点）
- 波音の音源は、歩ける範囲から 100 m 以内の部分の線だけを使います

## 水底の見た目（Bed look）

水の下から浜までの地面（Bed）の見た目は、Coast の `Bed look` で選びます。水の下と浜は同じ見た目になり、変更は Bake なしですぐ反映されます。

- 同梱のプリセット：`Pebbles`（小石、初期値）/ `Sand`（ベージュ〜茶色の砂浜）。Coast の `Pebbles` / `Sand` ボタンで切り替えられます
- 自分の見た目：Project で右クリック > Create > Clearwater > Bed Look。`Color`（色、必須・タイル状）と `Height`（高さ、任意。なければ色の明るさから推定）、1 枚が何 m 四方か（`Tile size`）を指定します
- 重ねる効果：隙間の砂（`Sand fill`）、波紋（`Ripple marks`。`Sand bed` をオンにすると底全体に）、藻の色（`Weed tint`）、色味（`Tint`・`Saturation`・`Brightness`・大きなまだら `Patchiness`・小石の落ち着いた色調 `Muted grade`）
- つや：`Smoothness`（Standard シェーダーの Smoothness と同じ意味。初期値 0 = つやなし）。水より上の乾いた地面に、空の映り込みと太陽のハイライトが付きます（0 のときは負荷も増えません）
- ユーザー地形に合わせる：Terrain source が User のとき、Coast の「Match the user terrain」で、ユーザー地形のテクスチャ・色・1 枚の大きさ・Smoothness から Bed look を作ります（下の「自分の地形を使う」）
- 同梱のテクスチャはどちらも計算で作ったもので、写真は使っていません（小石は移植元の `tools/make_pebbles.py`、砂は `Tools~/make_sand.py`）

## 自分の地形を使う（Terrain source: User）

歩ける範囲（緑の四角）の地面を、自分で作ったメッシュや Unity の Terrain にできます。岩場の入り江、岸壁のある港、プールなど、線と断面では作れない形に使います。

1. 地形のメッシュ・Terrain を一つの親オブジェクトの下にまとめます。当たり判定も自分で付けます（Mesh Collider・Terrain Collider など）
2. Coast の `Terrain source` を `User` にし、`User terrain` にその親を指定します
3. Coast の線を、歩ける範囲の端で地形の Waterline（波打ち際：地形が水面の高さ 0 と交わる所）に合うように描きます
4. Bake

Bake すると：

- 地形の見た目と当たり判定は、自分のマテリアル・コライダーのままです。Clearwater は地形を上から見た高さを焼き込み、水面の色・波・水底の光・海底をそれに合わせます
- 歩ける範囲の中では、地形が水面と交わる線を見つけて Waterline にします（描いた線はその外側の部分だけ使われます）。線を `Closed` にしたとき（プールなど）は差し替えないので、線を Waterline に合わせて描いてください
- プールだけのワールド：`Shore waves` をオフにし、線を `Closed` にしてプールを囲みます。水が見えるかどうかは地形の高さで決まるので（水面より低い所にだけ水が見える）、同じ水面の高さならプールがいくつあっても動きます。線は全部を囲む輪で構いません（1 つだけ囲んでも見た目はほぼ同じです）。海と一緒に置くプールや、高さの違うプール（建物の上の階・屋上）は、下の「プールを置く」を使います
- 地形の外側では、生成地形が `Seam width`（初期値 20 m）の幅の境目（Seam）で地形の縁の高さになめらかにつながります。遠くの海底や陸は生成地形のままです
- 地形の上には、水中の光の網（コースティクス）と波打ち際の濡れ・泡が 2 つのプロジェクター（水の下の「User Terrain Caustics」「User Terrain Beach」）で重なります。プロジェクターは地形と同じレイヤーにかかるので、そのレイヤーの他の物にもかかります
- 生成地形の当たり判定はオフになります（歩ける範囲の端の見えない壁は残ります）
- 駆け上がる波の速さと距離は、地形の波打ち際の傾きから決まります
- 地形を動かしたり作り替えたりしたら Bake し直します（Inspector が知らせます）

外側を同じ見た目にする：`Bed look` の「Match the user terrain」を押すと、地形の大部分を覆うマテリアル（Terrain なら一番多く塗られたレイヤー）のテクスチャ・色・1 枚の大きさ・Smoothness から Bed look を作り、シーンと同じフォルダに「（シーン名） Bed Look」として保存して選びます。境目の外側と遠くの海底が地形と同じ見た目になります。明るさなどはその Bed look で調整できます。

Unity の Terrain：高さは Terrain のデータから直接読みます（メッシュと重なる所は高いほう）。水底の平均の色と「Match the user terrain」は、塗られたレイヤーから取ります。標準の Terrain シェーダー（Standard）は、テクスチャのアルファを滑らかさとして使います。アルファ付きのテクスチャだと地面が鏡のように光るので、つや消しにしたいときは `Nature/Terrain/Diffuse` のマテリアルを Terrain に指定してください。

Bake で見つかった問題は、Coast の Inspector に番号付きの警告として出ます。Scene ビューには同じ番号の赤い印が出ます（「Show」でその場所を映します）：

| 警告 | 何が起きるか | 直し方 |
| --- | --- | --- |
| 歩ける範囲に、地形で覆われていない所がある | そこには立てる地面がなく、落ちる | 地形で覆うか、`Ground Half Size` を小さくする |
| 地形が、焼き込む範囲（歩ける範囲と境目）からはみ出している | はみ出した所に生成地形が重なって見える | 地形を小さくするか、`Ground Half Size` か `Seam width` を大きくする |
| 境目が急（高低差が境目の幅の 0.2 倍を超える） | 地形のまわりに土手や溝ができる | `Seam width` を広げるか、縁の高さが生成地形に近くなる所まで地形を延ばす |
| Coast の線が、歩ける範囲の端で地形の Waterline から 5 m 以上離れている | 波打ち際が端でずれる | 線の端を地形の Waterline に合わせる |

注意：

- 焼き込んだデータ（`Assets/Clearwater/Generated`）はプロジェクトに 1 組です。同じプロジェクトの複数のシーンで Clearwater を使うときは、シーンを開いたら Bake し直してください
- 負荷：地形の上のプロジェクターの分、波打ち際を見る視点で片目 +1.2〜1.7 ms ほど（RTX 4070 Ti SUPER・2048²）

## プールを置く（Clearwater Pool）

海とは別に、自分の高さの水面を持つプールをいくつでも置けます（リゾートの建物の 1 階の屋内プールや、2 階のテラスのプールなど）。水面・水中・光の模様・触ったときの波紋は海と同じ仕組みです。打ち寄せる波と波音はありません。

1. `Tools > Clearwater > Add Pool` で「Pool」を置き、プールの水面の高さに合わせます（オブジェクトの位置が水面です。回転はさせません）
2. 子の「Basin」の下に、プール本体のメッシュ（壁と底。まわりのデッキも入れて構いません）を入れます。当たり判定も自分で付けます。天井や飛び込み台は入れません（上から見て一番高い面が底として焼き込まれるため）
3. `Size`（水面の範囲、x と z）をプールの内側より少し大きめにします（水が見えるのは Basin が水面より低い所だけなので、大きめで構いません）
4. Pool の Inspector の **Bake**（Coast の Bake でもすべてのプールが焼かれます）

設定：

- `Wave Strength`：水面の揺れ（海の波を 1 として。初期値 0.35）。光の網の濃さも同じだけ弱まります
- `Indoor`：屋内。太陽の光（光の網・ギラつき・日の当たる底）がなくなり、空の代わりに部屋が映ります。部屋にリフレクションプローブを置いてください（Box Projection をオンに。VRChat では Baked が軽く、Realtime は重くなります）。プローブがないと部屋は映りません
- `Fog Distance`：水中の見通し（m）

Bake すると：

- プールの子に「Pool Water」（水面）、「Pool Underwater」（水中）、「Pool Caustics」（壁と底、プールの中のアバターに落ちる光の模様）ができます。素材は `Assets/Clearwater/Generated/Pools/` に保存されます
- 海はプールの範囲（上から見た範囲の、底から水面まで）に入り込みません。プールの底が海面や生成地形より低くても、海の水面・地面・光の模様は出ず、生成地形の当たり判定もその部分は抜かれます（プールを動かしたら Coast も Bake し直してください。Inspector が知らせます）
- どの水の中にいるかは、プールの範囲で判定します。頭がプールの中なら、プールの水中の表現と水中の音になります。波紋は、いる水（プールの上・中・すぐ横ならそのプール）にだけ付きます。画面や写真のカメラも、それぞれがいる水の水中の表現になります
- 下の階からは、上の階のプールを下から見た表現は出ません

Bake の警告（Pool の Inspector に番号付きで出て、Scene ビューに印が出ます）：水がない（Basin が水面より低くない、または天井などが入っている）／Basin が `Size` の外まで水面下に続いている／ほかのプールと同じ高さで重なっている／回転している。

できないこと：

- 水越しに別の水を見ること（ガラス張りのプール越しの海など）。奥の水は映りません
- プールの打ち寄せる波
- 回転したプール（範囲は軸にそろった四角です。斜めのプールはそれを囲む四角で）

負荷：プールが画面の多くを占める視点で、2048² あたり +0.6 ms ほど（RTX 4070 Ti SUPER）。見えていないプールは増えません。

## 物を置く（Clearwater Stamp）

海岸の上に置いた物は、`ClearwaterStamp` を付けてから Bake すると、海岸の一部として扱われます。

| モード | 使い方 | 効果 |
| --- | --- | --- |
| Obstacle | 水中に立つ岩・杭・流木など、実際に見える物に付ける | 波がその物に当たって砕け、周りに白波ができる。「Receive Caustics」で水中部分に光の網が落ちる（ClearwaterProps レイヤーに移動） |
| Raise Ground | 形を作るための見えないブラシ（任意のメッシュ） | その上面が地面になる（砂州・岩棚）。海底・歩ける地面・波がすべて追従 |
| Carve Ground | 同上 | その上面まで地面が掘られる（潮だまり・水路） |

ブラシは Bake 後に非表示になり、ワイヤーフレームで表示されます（アップロードには含まれません）。スタンプの周りには 30° ほどの斜面が自動で付きます。スタンプを動かしたら Bake し直してください。

## 調整

- 波の大きさ：水面と海底のマテリアルの `Breaker height` / `Run-up`
- 波打ち際の白波：`Whitewater height`（駆け上がる波の先端の盛り上がり、初期値 3 cm）/ `Foam relief`（泡の凹凸の陰影。近くで見るとき用、初期値 0 = なし。オンにすると波打ち際を近くで見る視点で片目 +2 ms ほど）
- 駆け上がりの速さと距離は、Bake のときに浜の傾きから自動で決まります（坂に投げたボールと同じ動き。緩い浜ほどゆっくり遠くまで）。浜の傾きは Coast の `Beach Slope`（初期値 0.1）
- 明るさ：`Sun intensity` / `Exposure`（水・海底・空・水中で同じ値に）
- 雲：空のマテリアル（Sky）の `Clouds`。`Cover`（0 = なし、初期値）、大きさ、流れる速さと向き。水面の反射・水中から見上げた窓・濡れた砂の映り込みにも同じ雲が出ます（インスペクターで変えると水面と海底のマテリアルにも自動でコピー）。流れるのはワールド実行中（Scene ビューでは Always Refresh をオン）。負荷は片目 +0.2〜0.4 ms ほど（Cover 0 なら増えません）
- 波紋・波音の音量：シーンの「Clearwater Controller」

## トーンマッピング（シェーダー内 / ポストプロセス）

初期状態では、水・海底・空・水中フォグの各シェーダーが自分の出力をトーンマップします。ワールドにポストプロセスは要らず、アバターの見た目も変わりません。

`Tools > Clearwater > Tone Mapping > In Post-processing (PPv2)` で、画面全体をまとめて Post Processing Stack v2 でトーンマップする方式に切り替えられます（`In Shaders` で元に戻ります）。

- 切り替えると：Clearwater のマテリアルの `Tone map in shader` がオフになり、「PostProcessing」レイヤー（なければ空いているユーザーレイヤーに作成）にグローバルな Post-process Volume、ワールドの Reference Camera に Post-process Layer が付きます。
- プロファイル `Assets/Clearwater/Generated/ClearwaterPost.asset`：シェーダーと同じトーンカーブを焼いた LUT（`ClearwaterToneLut.asset`、Color Grading の External モード）と、弱いブルーム。見た目はシェーダー内のときとほぼ同じです（平均 1/255 以下）。明るさはプロファイルの `Post-exposure`、ブルームもここで調整できます（切り替え直してもプロファイルは上書きしません）。マテリアルの `Exposure` を変えたときは、もう一度 `In Post-processing` を選ぶと LUT が焼き直されます。
  - PPv2 自身の ACES は明るい所の丸め方が違い、水中から太陽を見ると白い範囲が大きく広がるので使っていません。
- 良い点：シーン全体が同じトーンカーブになり、ブルームで太陽や水面のギラつきがにじみます。
- 注意：アバターにもトーンマップがかかり、色が少しくすんで暗めになります。負荷は片目 +0〜0.15 ms、ブルーム込みで +0.2〜0.3 ms（RTX 4070 Ti SUPER・2048²）。Quest ではポストプロセスが使えません。

## 水面すれすれのカメラ

カメラ（頭・画面・写真カメラ）が水面から 60 cm 以内にあるときは、画素ごとに水の上か下かを決めます。レンズが水面をまたぐと、画面の上側は水上、下側は水中（フォグ付き）に分かれて写ります。この間は水面・水中の処理が少し増えます。

## 負荷の目安

RTX 4070 Ti SUPER、VR（片目 2048²）で、水が画面いっぱいのとき片目 約 3ms。水中のカメラでは水面の描き方が変わり +0.7ms ほど。スタンプがあると +0.1ms 程度。

## 波音を作り直す

`Tools~/`（Unity には読み込まれないフォルダ）に、波音の加工手順があります。ffmpeg が必要です。

- `Tools~/make_wave_audio.sh <元の録音.flac>`：元録音から 3 種類のループ（`Runtime/Audio/*.ogg`）を作る
- `node Tools~/detect_wave_breaks.js`：波打ち際の音から波が砕ける瞬間を探し、波の時刻表（`Runtime/Audio/WavesShore_breaks.json`）を作る。波音を差し替えたら必ず実行する
